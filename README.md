门店独立管理后台与权限体系设计
连锁茶饮品牌的门店店长需要独立管理本店商品、订单、库存和员工，但不应看到其他门店数据，也不应修改总部品牌配置。门店独立管理后台正是为满足这一需求设计。每个门店拥有独立账号，登录后只能操作本店数据，总部可查看全部门店汇总数据。

系统采用RBAC权限模型，角色包括总部管理员、区域经理、店长、店员。总部管理员拥有全部门店和全局配置权限；区域经理管理指定区域内门店；店长管理本店商品、订单、员工和营业设置；店员仅能处理订单和核销取餐码。权限节点使用rule_name唯一标识，通过中间件在请求处理前进行权限校验。

门店数据隔离通过store_id字段实现。所有门店相关表（订单、商品关联、库存、员工）均包含store_id。后端查询时自动附加当前登录用户所属门店的store_id条件，确保门店只能看到本店数据。总部管理员查询时可不加store_id限制查看全部门店数据。

门店后台支持商品上下架、价格调整（在总部授权范围内）、库存管理、订单处理、退款审核、营业时间设置、门店公告发布。系统支持商品导入功能，门店可从总部商品库批量导入商品减少手动录入。打印机对接方面门店可配置小票打印机，接单后自动打印。

所有门店后台操作记录审计日志，包括操作人、操作时间、操作类型和操作内容。总部可随时查看各门店操作记录便于问题追溯和合规审计。关键操作如价格修改、退款审核需二次确认防止误操作。门店独立管理后台与完善权限体系是连锁茶饮系统实现“总部管控、门店自治”的组织保障，合理数据隔离和操作审计机制确保多门店运营安全规范。
